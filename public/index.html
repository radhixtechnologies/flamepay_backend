Flutter Super-App REST Endpoints

These endpoints are directly integrated with Dio in FlamePay Flutter Mobile App.

POST
/api/v1/auth/send-otp

Sends 6-digit OTP verification code to mobile.

POST
/api/v1/auth/verify-otp

Verifies OTP, returns JWT tokens and active User Profile.

GET
/api/v1/user/profile

Fetches authenticated user information & KYC status.

POST
/api/v1/user/kyc-submit

Submits Aadhaar, PAN and demographic details to verify account.

GET
/api/v1/wallet/balance

Returns live wallet balance, monthly limit, and spent amounts.

POST
/api/v1/wallet/transfer

Transfers wallet funds instantly via Mobile number or UPI ID.

GET
/api/v1/recharge/operators

Lists telecom & DTH operators with circles.

POST
/api/v1/recharge/pay

Executes prepaid recharge or utility bill payment.
